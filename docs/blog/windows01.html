パソコンの選び方と購入【2025年版】

パソコン購入場所の比較まとめ【2025年版】

購入場所ごとの特徴

メーカー直販（Dell / HP / Lenovo 等）

  • 価格：セールや構成によって変動するが、サポート・保証を含めて選びやすい
  • 性能：用途別の完成品が多く、ビジネス向けモデルも豊富
  • セキュリティ：新品・正規販売品を選びやすく、メーカー保証も利用できる
  • 補足：法人向けモデルや延長保証などもあり、安心・サポート重視の人に向く

家電量販店（ヨドバシカメラ / ビックカメラ 等）

  • 価格：販売価格だけでなく、ポイント還元や保証を含めて比較する
  • 性能：既製品中心。購入前にCPU・メモリ・SSD容量を確認する
  • セキュリティ：新品なら基本的に安心だが、不要な付属ソフトの有無は確認したい
  • 補足：実機を確認でき、店員に相談できる点がメリット

BTO（ドスパラ / マウスコンピューター / パソコン工房 / FRONTIER 等）

  • 価格：用途に合わせて構成を調整でき、コストパフォーマンスを重視しやすい
  • 性能：CPU・GPU・メモリ・SSDなどを用途に合わせて選択可能
  • セキュリティ：不要なソフトを増やさず、必要な構成に絞りやすい
  • 特典：分割手数料0円キャンペーンなどが実施される場合がある
  • 補足：ゲーミングPCやクリエイター向けPCが豊富。初心者は推奨構成から選ぶと失敗しにくい

中古ショップ（ソフマップ / 楽天中古PC 等）

  • 価格：新品より安く購入できる場合がある
  • 性能：旧世代モデルが中心。用途によっては十分実用的
  • セキュリティ：販売店による整備・初期化の内容を確認する
  • 補足：ノートPCはバッテリー状態、保証期間、返品条件を特に確認する

個人出品（メルカリ / ヤフオク 等）

  • 価格：安く購入できる場合がある
  • 性能：使用状況や改造状態など、個体差が大きい
  • セキュリティ：保証や販売後のサポートが限定的。OSやライセンスの状態も要確認
  • 補足：パーツやPCの状態を自分で確認できる人向け。初心者には販売店の中古PCを推奨

比較表（まとめ）

タイプ別おすすめ購入場所

  • ゲーマー・クリエイター → BTO
  • ビジネス利用・サポート重視 → メーカー直販
  • 学習・事務用で予算を抑えたい → 中古ショップ
  • 初心者で実機確認や店員への相談をしたい → 家電量販店
  • 価格を優先し、自分で状態確認できる → 個人出品

注意点（重要）

  • 分割手数料0円サービス：対象モデル・期間・支払回数などの条件を必ず確認する
  • 中古PC：バッテリー、SSDの状態、保証期間、返品条件を確認する
  • 個人出品：OS・Officeのライセンス状態、初期化状況、故障歴などを確認する
  • Office：PCに付属しているか、どのライセンス形態なのかを確認する

補足：Macは選択肢になる？

クリエイティブ用途ではMacも有力な選択肢です。 一方で、ゲーム・Windows専用ソフト・パーツ交換や構成変更を重視する場合は、 Windows PCやBTOのほうが適する場合があります。 OS、使用ソフト、周辺機器、予算を基準に選びましょう。

個人的結論（おすすめ）

  • BTO： ゲームやクリエイティブ用途では、必要なCPU・GPU・メモリ・SSDを選びやすく、 コストと性能のバランスを取りやすい。
  • 中古： 必要スペックを把握しているなら、新品より低価格で必要な性能を確保できる場合がある。

※分割手数料0円などのキャンペーンは時期・店舗・製品によって条件が変わるため、 購入時点の公式情報と総支払額を確認してください。

パソコンパーツ選び【2025年版】

初めに：2025年の基準

パソコンの性能や価格は短期間でも変化します。 このページでは2025年時点での目安をまとめていますが、 実際に購入するときは最新の価格・ベンチマーク・メーカー仕様も確認してください。

CPUについては、今回は比較対象をIntel製CPUに限定しています。 AMD製CPUについては対象外とします。

個人的に最低限と考えるスペック

用途 CPU メモリ ストレージ GPU 備考
事務・学習 Core i5 第11世代程度以上 16GB 500GB SSD 内蔵GPU可 Office・ブラウザ・動画など
ゲーム・編集 Core i7 / Core Ultra 7 クラス 32GB 1TB SSD 用途に応じたRTX等 ゲームや動画編集向け
プロ・高負荷作業 Core i7 / i9・Core Ultra 7 / 9 クラス 32〜64GB 2TB SSD 用途に応じた上位GPU 作業内容に合わせて構成

※CPU・GPUの必要性能はソフトによって大きく異なります。 「i9なら必ずプロ向け」というようにCPU名だけで判断せず、 実際に使用するソフトの推奨スペックを優先してください。

デスクトップとノート、それぞれのメリット

デスクトップPCのメリット

  • 冷却性能を確保しやすく、高負荷作業に向いている
  • メモリ・SSD・GPUなどを交換・増設しやすい
  • 同程度の予算ならノートより高い性能を選びやすい
  • 大型ディスプレイや複数モニターとの相性が良い

ノートPCのメリット

  • 省スペースで持ち運びできる
  • バッテリーを搭載しているため、短時間なら停電時にも作業を継続できる
  • Wi-Fi、カメラ、マイクなどが標準搭載されているモデルが多い
  • 一般的な事務・学習用途なら比較的低消費電力で利用できる

自宅で性能や拡張性を重視するならデスクトップ、 持ち運びや省スペースを重視するならノートPCが向いています。

1. OS

  • Windows 10： 2025年10月14日に通常サポートが終了。 2025年に新規購入するPCでは、基本的にWindows 11対応機を選ぶのがおすすめです。
  • Windows 11： TPM 2.0、Secure Boot、対応CPUなどのシステム要件を確認する。
  • 中古PC： 「Windows 11が起動する」だけでなく、Microsoftの公式要件を満たしているか確認する。

Microsoftの対応CPU一覧は「第○世代」という大まかな分類だけではなく、 CPUモデル単位で掲載されています。 中古PCを購入する場合は、CPU型番まで確認するのが安全です。

Windows 11のエディション

  • Home： 個人利用に適している。 対応PCでは「デバイスの暗号化」が利用できる場合がある。
  • Pro： BitLocker Drive Encryption、リモートデスクトップ、ドメイン参加など、 ビジネス・管理向け機能が追加される。

「Homeでは暗号化できない」という意味ではありません。 Windows Homeでも対応機種ではDevice Encryptionを利用できます。 Proではより管理性の高いBitLocker Drive Encryptionが利用できます。

補足：代替OS（Linux）

Windows 11に正式対応しない古いPCでは、Linux MintなどのLinuxディストリビューションを 選択肢にする方法もあります。 ただし、Windows専用の業務ソフトや一部ゲームなどが動作しない場合があるため、 必要なソフトがLinuxに対応しているか確認してから移行しましょう。

Linux Mint公式サイト

Officeライセンスの種類

  • Microsoft 365： 月額または年額制のサブスクリプション。 常に新しいバージョンのOfficeアプリを利用しやすく、 OneDriveなどのクラウドサービスも利用できる。
  • Office 2024： 一度購入して使用する買い切り型。 Office 2024のサポート終了日は2029年10月9日。
  • Officeプレインストール版： PC購入時に付属するライセンス。 ライセンスの種類・移行条件は製品ごとに異なるため、 中古PCでは付属品やライセンス状態を確認する。

Office 2024は買い切り型ですが、次のメジャーバージョンへの無償アップグレード権が 付属するわけではありません。 長期間の利用を考える場合はサポート期間も確認しましょう。

中古PC購入時のOffice注意点

  • Officeが付属しているか確認する
  • 付属している場合、どの製品・ライセンスなのか確認する
  • 「格安Office付き」「認証済みキー」などの説明だけで判断しない
  • 法人向けボリュームライセンスや教育機関向けライセンスの不正転売には注意する
  • Officeが必要なら、正規販売店やMicrosoft公式サービスから用意する

Officeライセンス確認のポイント

  • 商品名とライセンス形態を確認する
  • 中古PCではOfficeが本当に利用可能な状態なのか確認する
  • 購入後に自分のMicrosoftアカウントへ正規に登録できるか確認する
  • 価格だけでなく、サポート期間も確認する

Officeが不要な場合の選択肢

  • LibreOffice ：無料で利用できるオープンソースのオフィススイート。
  • Google Workspace ：企業向け有料サービス。
  • Google Docs / Sheets / Slides： Googleアカウントで利用できる無料サービスもある。

Office選択基準

  • 最新版・クラウド連携重視 → Microsoft 365
  • 買い切り重視 → Office 2024
  • 無料で済ませたい → LibreOffice / Google Docs・Sheets・Slides

2. CPU（Intel）

2025年のIntel CPUは、第14世代Coreだけでなく、 Core Ultraシリーズも選択肢になります。 中古PCでは従来のCore iシリーズ、新品ではCore Ultraシリーズも比較しましょう。

世代・シリーズの考え方

  • 第8〜9世代： Windows 11対応モデルは存在するが、2025年の新規購入では長期利用を考えて慎重に選ぶ。
  • 第10〜11世代： 事務・学習などではまだ実用的。中古PCの候補になる。
  • 第12世代： Pコア/Eコアのハイブリッド構成を採用し、性能と効率のバランスが良い。
  • 第13〜14世代： 高性能デスクトップ・ゲーミングPCなどで有力。ただし後述する不安定性問題に注意。
  • Core Ultra： 新世代のIntel CPUシリーズ。 モデルによってNPUなどを搭載し、AI処理を意識したPCでも採用されている。

用途別の目安

  • Core i5： 事務・学習・ブラウザ・軽い編集。 中古なら第11〜12世代程度以上を目安にすると選びやすい。
  • Core i7： 動画編集・3D・高負荷マルチタスク。 必要な性能は使用ソフトに合わせて判断する。
  • Core i9： 高負荷な動画編集・3D・配信など。 CPUだけでなく冷却・電源・GPUも重要。
  • Core Ultra 5 / 7 / 9： 新品PCを選ぶ場合の候補。 世代名だけでなく具体的な型番と性能を比較する。

CPUは「Core i5 / i7 / i9」という名称だけでは判断できません。 同じi7でも世代・型番によって性能や消費電力が大きく異なります。

CPU性能のイメージ

※これは性能を厳密に比較したランキングではなく、用途別の大まかな目安です。 実際の性能はCPUの世代・型番・電力設定・冷却性能によって変わります。

第13・14世代Intel Coreデスクトップの注意点

Intelは一部の第13・14世代デスクトップ向けCoreプロセッサで発生した Vmin Shift Instabilityについて原因と対策を公表しています。 中古PCを購入する場合は特に、BIOSの更新状況やメーカーの対応状況を確認しましょう。

  • BIOSを最新の安定版へ更新する
  • Intelの推奨設定やPCメーカーの設定を確認する
  • 中古品では過去の使用状況を確認できるなら確認する
  • 高額な中古第13・14世代CPUでは、保証の有無を重視する

3. メモリ（RAM）

  • 8GB：軽い事務用途の最低ライン。2025年の新規購入では16GBを推奨
  • 16GB：一般用途・仕事・学習・マルチタスクの標準的な目安
  • 32GB：動画編集・重いゲーム・開発・AIなどにおすすめ
  • 64GB以上：専門的な編集・仮想マシン・大規模データ処理など

DDR4とDDR5

  • DDR4：価格を抑えやすく、中古PCでも選択肢が多い
  • DDR5：新しいプラットフォームで採用され、帯域幅が広い

予算重視ならDDR4、新規構成や将来性を重視するならDDR5を検討するとよいでしょう。 ただし、マザーボードが対応しているメモリ規格を必ず確認してください。

4. ストレージ（SSD）

2025年にWindows PCを購入するなら、OS用ストレージはSSDを強く推奨します。 NVMe SSDは、SATA SSDより高速な製品が多く、現在のPCでは一般的な選択肢です。

容量の目安

  • 500GB：事務・学習・一般用途
  • 1TB：ゲーム・写真・動画編集など
  • 2TB以上：大量の動画・ゲーム・AIデータなど

SSD運用の注意点

  • 容量ギリギリまで使用せず、十分な空き容量を確保する
  • 重要データは外付けSSD・HDDやクラウドなどへバックアップする
  • 中古PCではSSDの健康状態・使用時間・総書込量などを確認する

中古SSDのチェック

中古PCを購入する場合は、S.M.A.R.T.情報を確認できるツールを利用すると、 SSDの使用状況を確認する材料になります。

CrystalDiskInfo などで健康状態・総書込量・使用時間などを確認できます。

SSDも故障する可能性があるため、バックアップは必須です。

5. GPU（グラフィック）

専用GPUがなくてもよいケース

  • 事務作業
  • Web閲覧
  • 学習
  • 動画視聴
  • 軽い画像編集

専用GPUが必要になりやすいケース

  • 3Dゲーム
  • 高解像度の動画編集
  • 3Dモデリング・レンダリング
  • ローカルAI画像生成・AI処理

GPUは「RTX○○ならすべての用途で十分」というものではありません。 ゲームの解像度・フレームレート、使用する編集ソフト、AIモデルのVRAM使用量などを確認して選びましょう。

VRAMの考え方

  • 一般的な事務用途 → 専用GPU不要の場合が多い
  • フルHDゲーム → ミドルレンジGPUを用途に応じて選択
  • WQHD・4Kゲーム → より高性能なGPUを検討
  • AI画像生成 → GPU性能だけでなくVRAM容量も重要

ノートPCでは同じGPU名でもデスクトップ版と性能が異なる場合があるため、 GPUの型番だけでなく消費電力・冷却性能・実際のベンチマークも確認してください。

補足：AI PC（Copilot+ PC）

2025年はNPUを搭載したAI PCが普及しています。 NPUは対応するAI処理の電力効率向上などに役立ちますが、 高性能なゲームや3D処理では、依然としてCPUや専用GPUの性能が重要です。

6. ディスプレイ

  • 仕事・事務：フルHD以上を目安
  • ゲーム：フルHD〜WQHD、必要に応じて高リフレッシュレート
  • 高解像度編集：WQHD〜4K
  • クリエイター：sRGBカバー率など色域・色精度を確認

ノートPCでは解像度だけでなく、明るさ、色域、リフレッシュレート、 パネル方式、バッテリー消費量も確認すると安心です。

7. Wi-Fi / ネットワーク

  • Wi-Fi 6：現在のPC選びで有力な選択肢
  • Wi-Fi 6E：6GHz帯に対応した環境でメリットがある
  • Wi-Fi 7：新しい規格。対応ルーターや利用環境との組み合わせで性能を発揮
  • ゲーミング：低遅延を重視するなら有線LANも有力

「Wi-Fi 7だから必ず速い」というわけではありません。 PC、ルーター、回線、設置環境などが対応しているか確認してください。

ノートPC特有の注意

  • バッテリーは消耗品として考える
  • 長時間の高負荷作業では冷却性能・騒音を確認する
  • メモリやSSDが交換できるか購入前に確認する
  • 将来必要になる性能を購入時点である程度確保する

端子・拡張性

  • USB-Cの仕様を確認する
  • USB4対応なら高速な周辺機器との接続に有利
  • Thunderbolt対応機では対応する機能・世代を確認する
  • HDMI、USB-A、SDカードスロットなど必要な端子を確認する

デスクトップ限定で重要なポイント

電源（PSU）

  • CPUとGPUの消費電力に合わせて容量を決める
  • 容量だけでなく、電源ユニットの品質・規格・保証も確認する
  • 高性能GPUを使用する場合は必要な電源コネクタを確認する

「i7なら○○W」という単純な基準ではなく、 CPU・GPU・ストレージ・増設予定などを合計して余裕を持たせるのが基本です。

マザーボード

  • CPUに対応したチップセット・ソケットを確認する
  • M.2スロット数を確認する
  • PCIeスロット数・世代を確認する
  • Wi-Fi・Bluetoothの有無を確認する
  • 将来のメモリ増設に必要なスロット数を確認する

冷却

  • CPUの消費電力とクーラーの性能を合わせる
  • 高性能CPUでは大型空冷や水冷などを検討する
  • ケースのエアフローも温度・騒音に影響する

ケース

  • GPUの長さを確認する
  • CPUクーラーの高さを確認する
  • ラジエーターを使用する場合は搭載スペースを確認する
  • 前面・背面のファン構成とエアフローを確認する

拡張性

  • デスクトップはノートPCより交換・増設しやすい
  • ただしBTO完成品では、ケースや電源によって拡張性が制限される場合がある

デスクトップ：拡張チェック早見表

項目 確認点 目的
拡張性 PCIe / M.2 / メモリスロット数 将来の増設に備える
電源 容量・品質・GPU用コネクタ 安定動作と将来のGPU交換
ストレージ M.2スロット・SATAポート・ヒートシンク 容量増設と発熱対策
クリアランス GPU長・CPUクーラー高・ラジエーター 物理干渉を防ぐ

BTO構成の目安

  • 事務・学習： Core i5クラス + 16GB RAM + 500GB SSD + 内蔵GPU
  • ゲーム・編集： Core i5 / i7クラス + 32GB RAM + 1TB SSD + 用途に合ったGPU
  • 高負荷・プロ用途： Core i7 / i9・Core Ultra 7 / 9クラス + 32〜64GB RAM + 2TB SSD + 上位GPU

BTOでは「売れ筋」や「推奨構成」をそのまま購入する方法もありますが、 自分が使用するゲーム・ソフトの推奨スペックを確認してから選ぶと、より無駄がありません。

まとめ（2025年版）

  • 一般用途：Core i5クラス + 16GB RAM + 500GB〜1TB SSD
  • ゲーム・編集：32GB RAM + 1TB SSDを目安に、用途に合ったGPUを選択
  • 高負荷作業：CPUだけでなくGPU・メモリ・冷却・電源までバランスを取る
  • ノートPC：性能だけでなく、重量・バッテリー・冷却・交換性も確認
  • デスクトップ：電源・冷却・マザーボード・ケース・拡張性を確認
  • Wi-Fi：Wi-Fi 6以上を基本候補として、利用環境に合わせて選ぶ
  • BTO：用途に合わせて構成を調整しやすい
  • 中古：CPUの対応状況、バッテリー、SSD、保証、OS・Officeライセンスを確認

第13・14世代Intelデスクトップ中古品の注意

中古で第13・14世代Coreデスクトップを購入する場合は、 BIOSの更新状況、メーカーの対応状況、保証の有無を確認してください。 IntelはVmin Shift Instabilityについてマイクロコードなどによる対策を案内しています。

最後に

同じ「Core i7」でも、世代や型番が違えば性能・消費電力・対応機能が大きく異なります。 また、パソコンはCPUだけで性能が決まるわけではありません。 メモリ、SSD、GPU、冷却、電源、ディスプレイなどを用途に合わせて選ぶことが重要です。

オーバースペックは予算の無駄になり、スペック不足は作業効率の低下につながります。 購入前には最新の価格、ベンチマーク、メーカー仕様、使用ソフトの推奨スペックを確認し、 自分の用途に合ったPCを選びましょう。

パソコン購入の実例（中古ノートPC）

※ Windows 10の通常サポートは2025年10月14日に終了しました。

普段はデスクトップを使用していますが、手持ちのノートPCがWindows 11の要件を満たさなかったため、 中古ノートPCを購入した実例です。

想定した用途は、 Excel・Wordを開きながらブラウザ、動画再生、Zoomなどを同時に利用できる程度の実用性能 です。

選んだ構成と理由（2025年9月時点）

  • 購入場所： ドスパラ（札幌店）
  • OS： Windows 11 Home

    ProではBitLocker Drive Encryptionなどの追加機能を利用できますが、 今回はコストを抑えるためHomeを選択しました。 なお、対応PCではHomeでもDevice Encryptionが利用できる場合があります。

  • CPU： Core i5 第12世代クラス

    Windows 11対応状況だけでなく、複数アプリを同時使用することを考慮して、 中古PCとして価格と性能のバランスが良い世代を選択しました。

  • メモリ： 16GB

    Office、ブラウザ、動画、Zoomなどを同時に使用するため、 8GBより16GBを優先しました。

  • ストレージ： SSD 500GB以上

    Windowsとアプリケーションの起動速度を考慮してSSDを選択。 500GB程度あれば、一般的な事務・学習用途では使いやすい容量です。

  • Wi-Fi： Wi-Fi 6対応

    Wi-Fi 6対応ルーターなどの環境で性能を活かしやすく、 既存のWi-Fi環境との互換性も考慮しました。

  • ディスプレイ： フルHD

    Officeやブラウザ中心の用途では十分な解像度と判断。 4Kよりも価格・消費電力・バッテリー持続時間とのバランスを優先しました。

  • その他： 冷却パッド

    ノートPCの温度対策として約3,000円の冷却パッドを併用しました。 ただし、冷却パッドがすべてのノートPCで必須というわけではなく、 PCの冷却設計や使用環境によって必要性は異なります。

購入結果

本体＋冷却パッド込みで 63,000円 で購入しました。

当時の個人的な購入判断では、同等クラスの中古・新品価格と比較して、 予算と用途のバランスが良いと判断しました。

ただし中古PCの価格は販売店、CPU世代、メモリ容量、SSD容量、 バッテリー状態、保証期間などによって大きく変わります。 「中古PCは必ず○万円安い」とは考えず、購入時点の相場と比較することをおすすめします。

中古ノートPCを選ぶときのポイント

  • Windows 11の正式対応状況
  • CPUの具体的な型番
  • メモリ容量と増設可能かどうか
  • SSDの容量・健康状態
  • バッテリーの状態
  • 液晶の傷・ドット抜けなど
  • キーボード・タッチパッドの状態
  • USB・HDMI・USB-Cなど端子の状態
  • ACアダプターが純正かどうか
  • 保証・返品条件
  • Officeの有無とライセンス状態

補足：バッテリー健全性のチェック

中古ノートPCでは、バッテリーの劣化状態も重要です。 バッテリーは使用時間や充放電回数によって劣化するため、 新品と同じ持続時間を期待しないほうが安全です。

  • 設計容量と満充電容量： 「Full Charge Capacity ÷ Design Capacity」を確認すると、劣化状態を判断する材料になる。
  • バッテリーサイクル： 回数が多いほど劣化している可能性があるため、参考情報として確認する。
  • 交換費用： 機種によって大きく異なるため、購入前に交換部品・修理費用を確認する。

「80％未満なら必ず交換」「300〜500回で寿命」というように、 数字だけで寿命を断定するのは避けましょう。 バッテリーの種類、使用環境、メーカー設計によって劣化状況は異なります。

中古PC購入の結論

中古PCは「安いから買う」のではなく、 必要な用途を決め、その用途を満たす性能・状態・保証を確認してから価格を比較する のが基本です。

特に2025年はWindows 10の通常サポート終了があるため、 中古PCを選ぶ場合は価格だけでなく、 Windows 11の正式対応状況を優先して確認することをおすすめします。
