1. 基礎概念：Deep Webとの違いとTorの位置づけ
概念 定義 具体例
Surface Web 検索エンジンで発見可能 Google検索で見つかるサイト
Deep Web 検索エンジン未登録の一般Web オンラインバンク、社内システム、会員ページ
Dark Web Tor/I2P/Freenet上の匿名Web .onionサイト、匿名掲示板

■ Tor（The Onion Router）の本質

  • 多層暗号化（オニオン構造）で中継ノードに経路を分散
  • 技術自体は違法ではなく、ジャーナリスト・告発者・一般市民のプライバシー保護に利用
  • 「犯罪専用」ではなく、検閲回避・匿名情報提供のインフラ
2. 実践：Tor BrowserとTails OS

■ Tor Browser 導入フロー

【入手】torproject.org 公式サイトのみ（非公式は悪意コードの危険）
   ↓
【起動】自動的にTorネットワーク接続 → 完了後、通常のブラウザとして利用可能
   ↓
【利用】.onionサイト + 通常のWebサイト両方アクセス可能
   ↓
【注意】ログイン情報や行動パターンから身元が推測されるリスクは残る

■ セキュリティレベル（右上の盾アイコン）

レベル JavaScript 用途
Standard 有効 通常閲覧
Safer 一部無効 不明サイト閲覧時の推奨
Safest 原則無効 セキュリティ最優先

■ Tails OS（The Amnesic Incognito Live System）

  • USBブート型Linux、Tor通信を中心に設計
  • 通常OSと完全分離、フィンガープリント対策標準装備
  • 保存データ・外部サービスログは別途管理が必要（自動消去ではない）
3. 技術：ルーティング、Bridge、VPN比較

■ オニオンルーティングの構造

利用者
  ↓（暗号化層1）
[Guard/Entry Node] ← 入口のみ知る
  ↓（暗号化層2）
[Middle Relay] ← 前後のノードのみ知る
  ↓（暗号化層3）
[Exit Relay] ← 出口のみ知る
  ↓
インターネット（※Torのみでは通信内容は暗号化されない → Tor+HTTPSが原則）

■ Tor Bridge（検閲回避技術）

方式 特徴 用途
obfs4 Tor通信を通常通信に偽装 Deep Packet Inspection回避
Snowflake WebRTC利用 ブロック厳しい環境
meek 特定Webサービス経由 ドメインフロンティング

■ Tor vs VPN 比較

項目 VPN Tor
経路 VPNサーバー1点 3ノード以上の多層中継
目的 通信保護・IP変更 匿名化・検閲耐性
.onion 不可 可能
組み合わせ Tor→VPN or VPN→Tor（用途により利欠点変化、単純な「より安全」ではない）
4. 応用：Onion Serviceとダークウェブの生態系

■ Onion Service（.onion）の特徴

  • サーバーの公開IPを隠したままサービス提供可能
  • Torネットワーク内完結、双方向の匿名性
  • 正規サービスの.onionアドレスは公式サイトで確認（リンク集は信頼不可）

■ サイバー犯罪エコシステム

脆弱性・認証情報 → Initial Access → 侵入 → データ窃取 → ランサムウェア → 身代金・再販売
        ↑
   【ダークウェブ流通物】
   ・流出データ（メール、パスワードハッシュ、企業情報）
   ・マルウェア・不正ツール
   ・アクセス権（Initial Access Broker）

■ 情報分析の5観点

観点 確認内容
日時 情報の鮮度
出典 一次情報の存在
証拠 第三者検証可能性
整合性 他情報源との一致
再現性 別情報源からの確認可能性

注意：匿名性が高いほど情報の信憑性チェックが重要

5. まとめ：Torを技術として理解する

■ 核となる理解

  • ダークウェブ ≠ 犯罪サイトの集合。匿名化ネットワーク上のWeb領域
  • Tor Browserは閲覧ツールであり、同時にOnion Service公開のインフラ
  • 匿名性は「魔法」ではなく、技術的制御と利用者の行動双方に依存

■ 技術要素一覧

Tor Browser Guard/Middle/Exit Relay Bridge（obfs4/Snowflake）
Tails OS Onion Service（.onion） フィンガープリント対策
Tor+HTTPS 検閲回避 脅威インテリジェンス

本質：「怪しいサイトを見る」ことではなく、 匿名化ネットワークの構造とその社会的・技術的意義を理解すること。
