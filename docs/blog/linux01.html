Linux(Fedora)の導入
Windowsから移行し、安全・軽快なPC環境を構築する方法

1. WindowsよりLinuxを選ぶ理由

※今回は、「安全性」「動作の軽快さ」「最新性」のバランスに優れた、汎用性の高いOSであるFedora Workstation (Fedora 44準拠)を導入します。（※標準のデスクトップ環境はGNOMEです）

■ メリット

  • 高度なアクセス制御と防御構造： Fedoraは強力な標準ファイアウォール（firewalld）や、システム侵入後の影響を最小限に抑える強制アクセス制御（SELinux）をデフォルトで標準稼働させています。重い常駐型サードパーティ製セキュリティソフトを追加せずとも、強固な権限分離構造を持っています。
  • 透明性とプライバシー保護： OSや利用するソフトウェアについて、収集されるデータや通信内容をユーザー自身が確認・選択しやすく、Windowsとは異なるプライバシー管理が可能です。
  • コスト・保守性の高さ： OS自体は完全に無料で利用できます。Windowsのようにライセンス購入費用がかからず、サポート終了時もPC本体を買い替えることなく、新しいバージョンのFedoraへ無料でアップグレードして使い続けられます。（※Fedoraは各バージョン約13ヶ月間サポートされます）
  • 柔軟性とカスタマイズ性： Windows 11では動作が重くなりやすいPCでも、Linuxではデスクトップ環境や構成を選択することで、より軽快に動作させられる場合があります。特に古いPCでは、軽量なデスクトップ環境を選ぶことで延命できる可能性があります。

■ デメリット

Windows専用のソフト（特定の動画編集ソフト、Officeデスクトップ版、特殊な専用ツール等）や一部の周辺機器（専用ドライバを必要とするプリンター等）が使えない、または設定が難しい場合があります。また、カーネルレベルのAnti-Cheat（不正防止ソフト）を必須とする一部のPCゲームは動作しません。

■ 結論

Webブラウザ上で動作する「Microsoft 365 (Web版Office)」や「Google Workspace」の利用、動画視聴、生配信の閲覧、Web閲覧、プログラミングや開発が中心であれば、Linuxに乗り換えるメリットは絶大です。

2. Fedora Workstation の導入方法

※Windows環境で準備作業を行います。

■ 必要なもの

  • 作業用のWindows PC
  • 8GB以上のUSBメモリ（内部データは全消去されるため事前バックアップ必須）
  • Fedoraを導入したいパソコン

■ 事前確認（お使いのPCとの相性チェック）

一部のPC（グラフィックボードやWi-Fiのパーツの種類によって）では、画面の表示やWi-Fi接続に少し設定が必要になることがあります。
後述の「お試し画面（ライブ環境）」が立ち上がった時に、画面がきれいに映るか、Wi-Fiに繋がるかを触って確認しておくと安心です。（※映像用パーツ（NVIDIA）が入っているPCの場合は、インストール途中で「サードパーティリポジトリ」をONにすると必要な設定がスムーズに行われます）

■ 手順

1. 書き込みソフト（Rufus / Fedora Media Writer）の準備

Rufus公式サイト（https://rufus.ie/ja/）より最新のPortable版（rufus-x.xxp.exe）をダウンロードします。
※Fedora公式の書き込みツール「Fedora Media Writer」を使用することでも同様に作成可能です。

2. FedoraのISOイメージをダウンロードと整合性検証（推奨）

公式サイト（https://fedoraproject.org/workstation/download/）より「Fedora Workstation Live ISO」をダウンロードします。

【安心チェック：ファイルが正しくダウンロードできたか確認する（任意）】
ファイルが途中で壊れたり、偽物にすり替わったりしていないか心配な方は確認できます。（※スキップしても次に進めます）

  1. PowerShellを開く
    Windowsの「スタートボタン」を右クリックして、出てきたメニューから「PowerShell」（またはTerminal）をクリックして開きます。
  2. コマンドを入力する
    画面が開いたら Get-FileHash と入力します。
    ※ Get-FileHash と打ち、キーボードのスペースキーを半角で1回押します（全角スペースになるとエラーになるので注意してください）。
  3. ファイルを画面にドラッグ＆ドロップする
    ダウンロードしたFedoraのファイルを、PowerShellの画面内にマウスで引っ張って入れます（ドラッグ＆ドロップ）。すると、保存先のパスが自動入力されます。
  4. Enterキーを押す
    キーボードの Enter キーを押します。
  5. 結果を確認する
    画像のように「Hash」の下に表示された長い英数字（例: 1620295F...）が、公式サイトのダウンロードページにある「CHECKSUM」の英数字と一致していれば、ファイルは壊れておらず100%安全です。

3. USBメモリにISOイメージを書き込む

  • USBメモリをWindows PCに接続します。
  • Rufusを起動し、「デバイス」で挿入したUSBを選択します。
  • 「ブートの選択」で、ダウンロードしたFedoraのISOファイルを選択し、「スタート」をクリックします。

※「ISOイメージモード / DDイメージモード」を選択する画面が出た場合は、画面の案内に従い「ISOイメージモード（推奨）」を選択して実行します。
※書き込み完了後、USBメモリを安全に取り外します。

4. 導入対象のPCをUSBから起動する

【セキュリティのワンポイント：Secure Boot（機能維持）】
UEFI対応PCでは、Secure Bootを可能な限り有効にしたままFedoraを導入してください。Secure Bootは起動時に許可された署名済みブートコンポーネントを検証し、OS起動前の改ざんに対する防御に役立ちます。無効化するとこの保護機能が失われるため、特別な理由がない限り有効のまま使用します。

  • Fedoraを入れたいPCにUSBメモリを挿入し、電源を入れます。
  • 電源オン直後に F12（または F2 / F11 / Delete ※メーカーによる）を連打し、ブートメニューを開きます。
  • ブートメニューから「USB Flash Drive」を選択して起動すると、Fedoraのライブ環境（お試し画面）が立ち上がります。

5. インストール手順に従う

  1. インストーラーの起動： 画面の「Install to Hard Drive」をクリックします。
  2. 言語選択： 「日本語」を選択して「続行」をクリックします。
  3. インストール先と暗号化設定：
    • 「インストール先」をクリックし、Fedoraを入れるストレージ（SSD/HDD）を選択します。
    • 【パスワード設定①】 セキュリティを高める場合は「データを暗号化する」にチェックを入れ、暗号化用パスフレーズを設定します。
  4. サードパーティリポジトリ： 必要なソフトウェア（NVIDIAドライバや一部のプロプライエタリなコーデック等）を利用する場合に有効化します。不要な場合はチェックなしで進めます。
  5. 【パスワード設定②】ユーザーアカウント作成：
    • 「ユーザー作成」をクリックし、ユーザー名とログイン用パスワード（管理コマンド実行時にも使用）を設定します。
  6. インストールの実行と再起動： 「インストール開始」をクリックし、完了後PCを再起動してUSBメモリを取り外します。

【重要：セキュリティと設定する2つのパスワードについて】
・1つ目（ストレージ暗号化）： PCの紛失・盗難時にSSDを取り出されてデータを直接読み出されるリスクを防ぎます。暗号化解除に必要な認証情報を失うと、暗号化されたストレージ上のデータへアクセスできなくなる可能性があります。重要なデータは必ず別媒体にもバックアップしてください。
・2つ目（ユーザーアカウント）： 日常のログインや管理権限コマンド（sudo）の実行時に使用します。
※セキュリティ上、2つのパスワードは必ず別々に設定することを強く推奨します。（※ユーザーパスワードは導入後に「設定 ＞ ユーザー」または `passwd` コマンドからいつでも変更可能です）

3. ツールの追加・セキュリティ設定

■ セキュリティの全体構造（多層防御の役割分担）

Secure Boot： OS起動前のブートローダー改ざん防止・検証
ストレージ暗号化（LUKS）： PC紛失・盗難時の保存データ物理保護
SELinux / firewalld： システム全体のプロセス権限制限・ネットワーク制御
Proton VPN（WireGuard / Kill Switch）： 通信の暗号化・盗聴防止・IP保護
Firefox + uBlock Origin： Web閲覧時の広告・トラッカー・悪質コンテンツの遮断
Proton Pass： パスワードの安全な管理と使い回し防止
ClamAV： ダウンロードファイル等のオンデマンド（手動）スキャン
3-2-1バックアップ： システム障害・ランサムウェア被害・誤操作時の最終防衛線

■ Flatpakエコシステムの拡張（Flathubの追加）

Fedoraは標準でFlatpakパッケージに対応していますが、世界最大の統合リポジトリ「Flathub」を追加登録することで、さらに多くの安全にサンドボックス化されたアプリ（Spotify、Discord、VS Code等）をGUI（ソフトウェアセンター）から簡単に導入できるようになります。

flatpak remote-add --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo

■ プライバシー・通信保護ツール（Proton）

● Proton VPN（Proton公式のLinuxアプリ）

通信の保護および公共Wi-Fi等での盗聴を防ぎます。（※Fedora 44環境における公式推奨セットアップ手順）

1. 公式リポジトリパッケージの登録
※URL内のパッケージバージョン（`1.0.4-1`等）は将来変更される可能性があるため、公式手順の最新状態をご確認ください。

wget "https://repo.protonvpn.com/fedora-$(cat /etc/fedora-release | cut -d' ' -f 3)-stable/protonvpn-stable-release/protonvpn-stable-release-1.0.4-1.noarch.rpm"
sudo dnf install ./protonvpn-stable-release-1.0.4-1.noarch.rpm -y

2. パッケージ情報の更新とアプリ本体のインストール

sudo dnf check-update --refresh
sudo dnf install proton-vpn-gnome-desktop -y

【おすすめ推奨設定（セキュリティ重視構成）】
アプリを起動してログイン後、設定（Settings）より以下のように設定します。
【NetShield：ON】【Kill switch：ON（より厳格な遮断を求める場合は Advanced Kill Switch を推奨）】【Split tunneling：OFF（※LinuxではKill Switchとの併用制限があるため）】【Protocol：WireGuard】【VPN Accelerator：ON】【IPv6：基本はデフォルト設定】【Auto connect：ON】

● Proton Pass

Firefoxのアドオンストア（Proton Pass ページ）より追加。暗号化されたパスワードマネージャー。パスワードの使い回しを防ぎ、アドレスの隠蔽（メールエイリアス機能）が可能です。

■ ブラウザ（Firefox）のおすすめ拡張機能

拡張機能を増やしすぎるとかえってブラウザが重くなったりトラブルの原因になります。必要最小限の構成が最も安全です。

  • uBlock Origin: 必須。広範囲な広告・トラッカー・悪質スクリプトの遮断。
  • ClearURLs: 必要に応じて。URLに含まれる追跡用パラメータ（?utm_source=等）の自動削除。

■ ClamAV + ClamTk（ファイル用スキャン機能の追加）

一般的なデスクトップ利用ではWindowsのような常時リアルタイムスキャンを必須とする必要はありません。ただし、メール添付ファイルや外部から取得したファイルをチェックする補助対策（オンデマンドスキャン）として導入します。
ターミナル（端末）を開いて、以下のコマンドを実行します。

sudo dnf install clamav clamav-update clamtk -y

・ウイルス定義データベースの手動更新

sudo freshclam

■ オンライン確認ツール・外部サービス

  • VirusTotal： ダウンロードしたファイルや不審なURLは、開く前にこちらへアップロード・入力して多角的に安全性を判定します。
    ※機密情報・個人情報・社内情報などを含むファイルは、利用規約や組織のポリシーを確認せずにアップロードしないでください。
4. メンテナンスと保守運用

PCを安全に保つため、必要に応じて以下のメンテナンスを行います。（※毎日起動時に実行する必要はありません）

■ ① 通常のシステム更新（週1回〜月1回程度）

システムパッケージとFlatpakアプリを更新します。（※重大な脆弱性が報じられた場合は、定期更新を待たずに即座に実行してください）

sudo dnf upgrade --refresh -y && flatpak update -y

■ ② ダウンロードファイルの安全性確認（不審なファイル取得時）

ホームディレクトリ全体のフルスキャンは時間がかかるため、ダウンロードフォルダや特定の不審なファイルに対象を絞って実行するのが実用的です。

sudo freshclam && clamscan -r -i ~/Downloads

【実行結果の見方】
「Infected files: 0」と表示された場合、『今回のClamAVスキャンでは既知の検出対象は見つからなかった』ことを意味します。

■ ③ システム掃除（月1回程度またはストレージ整理時）

不要になった依存パッケージやキャッシュを削除します。

sudo dnf autoremove -y && flatpak remove --unused -y && sudo dnf clean all

■ ④ セキュリティ機能（SELinux / ファイアウォール）の動作確認

echo -e "=== SELinux ===\n$(getenforce)\n\n=== Firewalld ===\n$(sudo firewall-cmd --state)"

【正常時の出力結果】
=== SELinux ===
Enforcing （※アクセス制限が正常有効）

=== Firewalld ===
running （※ファイアウォールが正常稼働中）

【発展編：詳細なファイアウォール設定の確認】
現在適用されているゾーンや公開されているサービスを確認したい場合は、以下を実行します。外部から意図しないサービスが公開されていないことを確認できます。

sudo firewall-cmd --get-active-zones && sudo firewall-cmd --list-all

■ ⑤ 最終防衛線：データバックアップ（3-2-1ルールの推奨）

どんなにセキュリティを高めても、SSDの突然の物理故障、PCの落下・破損、パスフレーズの紛失、ランサムウェア被害、人間による誤操作を防ぐことはできません。

  • 3-2-1バックアップルール： 重要なデータは「3つ以上のコピーを作成し、2種類以上の異なる媒体に保存し、そのうち1つはPCから物理的・論理的に分離された場所（クラウドや取り外した外付けSSD）」に保管することを強く推奨します。
  • 復元テストの実施： バックアップを取るだけでなく、「実際にデータを復元して正常に開けるか」を定期的にテストしてください。データ破損による復元不能を防ぎます。
  • 物理的切り離し： 外付けSSD/HDD等へバックアップを取る場合、ランサムウェア被害などによる同時破損を防ぐため、バックアップ完了後はPCから常時接続したままにせず必ず取り外して保管してください。
  • Fedora標準搭載の「バックアップ（Déjà Dup）」ツールなどを利用すると、自動暗号化バックアップが簡単に構築できます。
セキュリティについての重要な注意 本ガイドで紹介している設定や手順は、PC環境の安全性を高めるための「多層防御」のアプローチであり、マルウェア感染、フィッシング詐欺、アカウント乗っ取り、データ消失などを完全に防止することを保証するものではありません。 OS・ソフトウェアを最新の状態に保つ、不審なリンクやファイルを不用意に開かない、管理者権限（sudo）を安易に与えない、パスワードを使い回さない、重要なデータを二重・三重にバックアップするといった基本的な運用ルールを継続することが同様に重要です。 特に `sudo` を伴うコマンドはシステム全体へ影響を与えるため、内容や動作を理解したうえで慎重に実行してください。
