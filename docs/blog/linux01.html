〈概要〉WindowsよりLinuxを選ぶ理由

【メリット】
・セキュリティ・プライバシー面： Linuxは強固なファイアウォール（firewalld）や強制アクセス制御（SELinux）を標準備えています。Windowsのように重い常駐型サードパーティ製セキュリティソフトを入れずとも高い防御力を持っています。ネットワーク防御、ブラウザ分離・隔離、トラッキング防止にも優れ、OS自体によるログ追跡も少ないのが特徴です。

・種類が豊富： 初心者向けの「Linux Mint」や、最新技術と安定性を兼ね備えた「Fedora」など、用途に合わせて選べます。

・料金面・サポート期限： 完全に無料で導入・アップデートが可能です。Windowsのように購入費用がかからず、OSのサポート終了による強制的な買い替えリスクもありません。

・軽量で古いPCも復活： Windows 11では動作が重くカクつく低スペックパソコンでも、Linuxならサクサク動作します。PCの廃棄や無駄なパーツ増設を回避できます。

【デメリット】
Windows専用ソフトや一部周辺機器が使えない、または設定が難しい場合があります。また、一部のPCゲーム（Anti-Cheat搭載等）は動作しません。

【結論】
Webブラウザ利用（Office Web版、Google Workspace）、動画視聴、事務作業、プログラミングや開発が中心であれば、乗り換えるメリットは絶大です。今回は「安全性」「動作の軽快さ」「最新性」のバランスが最も優れている万能かつ強力なOS、Fedora Workstationを導入します。

〈手順〉Fedora Workstation の導入方法

※Windows環境で作業を行います。

【必要なもの】
・作業用のWindows PC
・8GB以上のUSBメモリ（内部データは全消去されるため事前バックアップ必須）
・Fedoraを導入したいパソコン

1. Rufus（書き込みソフト）のダウンロード
公式サイト（rufus.ie）より最新のPortable版をダウンロードします。

2. FedoraのISOイメージをダウンロード
公式サイト（fedoraproject.org）より「Fedora Workstation Live ISO」をダウンロードします。

3. USBメモリにISOイメージを書き込む
・USBを接続し、Rufusで「デバイス」を選択。
・「ブートの選択」でダウンロードしたISOファイルを選択し「スタート」をクリック。
※画面指示が出た場合は「ISOイメージモード（推奨）」を選択します。

4. 導入対象のPCをUSBから起動する
・対象PCにUSBを挿し、電源オン直後に F12（または F2 / F11 / Delete）を連打してブートメニューを開き、「USB Flash Drive」を選択します。

5. インストール手順に従う
・「Install to Hard Drive」をクリック ＞ 言語：「日本語」 ＞ インストール先SSD/HDDを選択。
・暗号化設定 (LUKS)：「データを暗号化する」にチェックしパスフレーズ設定（任意）。
・「サードパーティのリポジトリを有効にする」にチェックを入れてインストールを開始します。

〈設定〉ツールの追加・セキュリティ設定

～ ClamAV + ClamTk（ウイルススキャン機能） ～
ターミナルを開いて実行します。
・パッケージインストール：
sudo dnf install clamav clamav-update clamtk -y
・初回定義更新：
sudo freshclam

～ ブラウザ（Firefox）のおすすめ拡張機能 ～
・uBlock Origin: 広告・トラッカー遮断
・Privacy Badger: 未知のトラッカー自動検知
・ClearURLs: 追跡用パラメータ削除
・Malwarebytes Browser Guard: 詐欺・フィッシングブロック

～ 有料セキュリティ・プライバシー ツール ～
・Proton VPN（公式Linuxアプリ）
【コマンド】
wget https://repo.protonvpn.com/fedora-$(rpm -E %fedora)-relative/protonvpn-stable-release/protonvpn-stable-release-1.0.3-1.noarch.rpm
sudo dnf install ./protonvpn-stable-release-1.0.3-1.noarch.rpm -y
sudo dnf check-update --refresh && sudo dnf install proton-vpn-gnome-desktop -y
【推奨設定】
NetShield:ON / Kill switch:ON / Protocol:WireGuard / VPN Accelerator:ON / Auto connect:ON 等

・Proton Pass
Firefoxアドオンストアより検索して追加。エンドツーエンド暗号化パスワードマネージャー。

～ オンライン確認ツール ～
・VirusTotal：怪しいファイルやURLを一括判定。

〈コマンド〉日常・週1メンテナンス

① 日常の起動時に使う「爆速メンテナンス」
sudo dnf upgrade --refresh -y && flatpak update -y && sudo dnf autoremove -y && sudo dnf clean all && flatpak remove --unused -y

② 週1回または不安な時に使う「フルチェック＋ウイルススキャン」
sudo dnf upgrade --refresh -y && flatpak update -y && sudo dnf autoremove -y && sudo dnf clean all && flatpak remove --unused -y && rm -f ~/scan_result.log ~/clamav_scan.log && sudo freshclam && clamscan -r -i ~ -l ~/scan_result.log
※最後「Infected files: 0」なら安全です。

③ セキュリティ機能（SELinux / ファイアウォール）の動作確認
echo -e "=== SELinux ===\n$(getenforce)\n\n=== Firewalld ===\n$(sudo firewall-cmd --state)"
※正常時：SELinux (Enforcing) / Firewalld (running)
