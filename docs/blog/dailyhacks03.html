部屋の清潔感

はじめに

「落ちたものを食べても3秒以内なら大丈夫」という言い伝えがありますが、菌は一瞬で付着し、寒天培養で1日で増殖しました。古い物件の独特の臭いも、前住人のバクテリアや体臭が壁や床にしみ込んだものです。

こうしたニオイや菌の問題を放置すると、カビ・ウィルス・バクテリアはもちろん、昆虫（ゴキブリ・ダニなど）の住処にもなります。今回は市販でコスパ良く、UV-Cやオゾンなどを活用し、カビ・ウィルス・バクテリア対策（＋昆虫）として最高の環境作りをまとめました。


年に数回実施

市販で手に入る空間除菌手段として、UV-Cとオゾンが最強クラスです。

・UV-Cライト

紫外線による除菌で、カビ・ウィルス・バクテリアに効果があります（昆虫には限定的）。人体やペット、植物にも有害なため、使用時は避難が必要です。

使用後は独特の臭い（オゾンや有機物分解による）がしますが、これは効果があった証拠です。光が一直線しか進まないため、影になる部分は殺菌できないことです。いろんな角度から何度も照射する必要があります。

プラスチックや繊維によっては変色・劣化する可能性があるため注意が必要です。動物や植物はもちろん、人間も直接見ないようにしましょう。

→ Philips UVC 除菌ライト

・オゾン

空間除菌・消臭を行います。部屋を閉め切ってオゾン濃度を上げ、十分な作用時間を確保した後、換気して排出することが重要です。人体やペットにも有害なため、運転中は避難が必須です。昆虫にも一定の駆除効果があります。

今回はオゾンサーキュレーターで洗濯物や空間の消臭に便利な、マクセル オゾネオ部屋干しネクスト MXAP-ARD200 がおすすめです。

・次亜塩素酸

日ごろ使う場合は高価になるため、年に数回拭き取り用に希釈して使用するのがおすすめです。厚生労働省等は有人環境での空間噴霧を推奨していません。吸入リスクがあるため空間噴霧は避け、壁や床の拭き取りに限定してください。

→ 【プロ使用実績あり】超強力消臭スプレー 300ml 無香料 暮らし工学Labo


日常の空間消臭(家電)

・除湿器（コンプレッサー式）

湿度が高すぎるとカビやゴキブリ等の昆虫の住処になってしまいます。除湿器は湿度を下げることで、カビの繁殖を抑え、昆虫（ゴキブリ・ダニ）が好む湿気の多い環境を作らないため、予防効果があります。衣類を早く乾かす面でも活躍します。安価なモノでも構いませんが、コンプレッサー式を選んでください。

→ 山善 除湿機 衣類乾燥 除湿器 コンプレッサー式 小型 強力除湿 除湿量 3.8L

・スチームアイロン

洗えないベッドマット等、ダニやカビを一時的に対策できます。高温スチームは昆虫（ダニ）にも一定の効果があります。

→ パナソニック 衣類スチーマー コンパクト ホワイト NI-FS420-W

・ハイター

月1回程度、流し台や洗面台、トイレのタンク内に入れて30分後に流すと消臭・除菌効果があります。他の洗剤（酸性・塩素系以外）と混ぜると塩素ガスが発生し危険です。必ず単独で使用してください。

→ ハイター 漂白剤

・パイプユニッシュ・ドメスト

月1回程度、流し台や洗面台、風呂場ならパイプユニッシュ、トイレならドメストを流し込んで30分後に流すと、消臭やつまり予防になります。パイプ内のヌメリ（バクテリアの塊）を除去することで、昆虫（ゴキブリ）の食源・住処を減らせます。

→ パイプユニッシュ（排水口・パイプ用洗浄剤）
→ ドメスト（トイレ用洗浄剤）

・エアコンの清掃

エアコン清掃後、らくハピ エアコンのニオイ・カビ オールアタックをスプレーし、カビピカを設置すると効果的です。エアコン内部のカビ・ダニ対策になります。

→ らくハピ エアコンのニオイ・カビ オールアタック
→ カビピカ エアコン用 防カビバイオ
